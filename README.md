## 这是什么东西

你大坝的。简历。

我不是应该把经历往文档里一贴，写几句“负责相关工作”“参与项目推进”“具备良好沟通能力”，然后 HR 当场拍桌说：这个同学很有潜力吗。

我不是应该顺理成章投递、面试、offer、入职，坐进工位，喝上咖啡，打开飞书，开始我的职场新人生吗。

不是都说简历是第一张名片吗。不是都说要结果导向吗。不是都说 STAR 法则一套，面试机会就到手吗。

哦哦。你们搞错了吧。

现实是：

```text
经历是真的。
项目是真的。
加班是真的。
复盘是真的。
但写出来像“本人积极参与相关事项”。
```

这怎么投。

所以有了这个东西。

它是一个中文简历优化 Prompt / Skill 规则集。  
主要负责把你的简历从“看起来做过一点事”，抢救成“看起来真的能干事”。

不是替你编人生。  
不是把你包装成 19 岁主导集团战略转型。  
不是把校园项目写成商业帝国起源。

它只做一件事：

```text
在不编的前提下，把你做过的事写得更像人话。
```

---

## 谁适合用

适合这些正在和简历互相折磨的人：

- 实习投递
- 校招投递
- 暑期实习投递
- 产品经理方向
- 用户运营 / 内容运营 / 增长运营
- 品牌 / 市场 / 商业化方向
- 用户研究 / 商业分析方向
- 项目经历很多，但看起来像散装人生
- 明明干了不少，写出来像会议纪要
- 简历改了七版，还是觉得自己像路过这个项目

尤其适合这种状态：

```text
你知道自己做了什么。
但简历不知道。

你知道项目有价值。
但 bullet 不知道。

你知道自己不是废物。
但“负责相关工作”这六个字看起来很像。
```

## 怎么用

非常简单。

你只需要做三件事：

```text
1. 打开 skills/resume-polisher-zh/SKILL.md
2. 把全文复制 / 上传 / 丢给 AI
3. 再补一句你的需求 prompt
```

支持任何能读长文本的 AI：

| 平台 | 用法 |
|---|---|
| 豆包 | 把 `SKILL.md` 丢进对话 / 智能体设定 |
| Kimi | 上传或粘贴 `SKILL.md` |
| 通义 / 文心 / 扣子 | 当提示词或智能体规则使用 |
| ChatGPT / Claude / Gemini | 粘贴 Skill，再输入简历和 JD |
| 其他 AI | 能读文件就行，不能读就复制全文 |

推荐 prompt：

```text
请严格按照这份 Resume Skill 执行。
下面是我的简历和目标岗位，请输出一版中文一页简历终稿。
不许编经历，不许编数据，不许把我写成我自己都不认识的人。
```

如果你有 JD，可以这样写：

```text
请严格按照这份 Resume Skill 执行。
下面是我的简历和目标 JD，请帮我做一版 JD 定向优化。
要求：保留真实经历，不虚构数据，不硬套 JD 关键词，输出可以直接粘贴进简历模板。
```

然后把你的简历和 JD 丢进去。

接下来就看 AI 表演，但不要完全闭眼。  
它如果开始把“协助整理资料”写成“主导业务中台建设”，请立刻把它摁住。

## 它会干嘛

它会尽量帮你：

- 把重点往前放
- 把动作写清楚
- 把数字捞出来
- 把废话剪掉
- 把“参与了”改得更具体
- 把“负责相关工作”拆成真实动作
- 把一堆散装经历压成一页简历
- 把简历改成 HR 和业务面试官比较容易扫懂的版本

它不会帮你：

- 编数据
- 编 title
- 编成果
- 编公司
- 把协助写成主导
- 把普通项目写成改变行业格局
- 把 JD 关键词像火锅底料一样全倒进去
- 把你写成你自己看了都想问“这谁啊”

## 输出大概长这样

```text
姓名 手机号（手机/微信） 邮箱 年级 / 到岗时间

教育经历
本科：学校 - 专业 日期
主修课程：...

实习经历
公司 / 部门 职位 日期
- 项目/模块（核心成果：...）
- 【能力概括】 动作 + 方法 + 产出/结果
- 【能力概括】 动作 + 协同对象 + 产出/结果

个人项目
项目名称 / 角色 日期
- 【能力概括】 动作 + 方法 + 产出/结果

专业能力
- AI工具使用：...
- 产品原型绘制：...
- 数据分析能力：...
- 英语能力：...
```

---

## 它的底线

这个 Skill 的底线很简单：

```text
不编。
不飘。
不硬装。
不把空气写成项目成果。
```

可以优化表达。  
可以调整结构。  
可以提炼重点。  
可以把你的经历写得更清楚。

但不能把没有发生过的事写成发生过。  
简历可以变强，但不要变成平行宇宙入口。
